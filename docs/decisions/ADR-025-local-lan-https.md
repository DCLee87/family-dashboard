# ADR-025: 로컬 전용 기기의 LAN HTTPS 진입 경로

- 상태: 승인, TV 호환성 검증 필요
- 결정일: 2026-07-29

## 배경

Tailscale Serve는 부모 PC·모바일의 사설 외부 HTTPS 경로지만, TV와 공용
태블릿은 로컬 전용 정책 때문에 이 경로에서 등록하거나 자격정보를 사용할 수
없다. 컨테이너의 HTTP 포트를 LAN에 직접 공개하면 Secure 쿠키와 인증정보를
평문으로 전송하게 된다. 공개 도메인이나 공유기 포트 포워딩을 추가하지 않고
집 안 기기에 HTTPS를 제공할 별도 진입 경로가 필요하다.

## 결정

- Synology Reverse Proxy가 LAN의 `yong.local` HTTPS를 컨테이너의
  loopback `127.0.0.1:8080` HTTP로 전달한다.
- 공유기에는 LAN HTTPS 소스 포트의 포트 포워딩을 만들지 않는다.
- E2 로컬 CA가 서명한 1년 서버 인증서를 사용한다.
- 서버 인증서는 `yong.local` DNS 이름과 NAS의 현재 LAN 주소를 SAN으로
  포함한다.
- 로컬 CA 공개 인증서는 사용하는 가족 기기에만 신뢰 루트로 설치한다.
- CA 개인키는 강한 암호로 AES-256 암호화한 파일만 보관한다.
- 평문 CA 개인키와 DSM에 가져온 서버 개인키의 로컬 사본은 암호화본 확인
  후 제거한다.
- Tailscale Serve 신원 헤더가 있는 요청은 Docker 프록시 주소가 로컬
  CIDR이어도 외부 요청으로 분류한다.

## 결과

- LAN에서도 Secure·HttpOnly 쿠키를 유지할 수 있다.
- Tailnet 경로와 LAN 경로를 같은 애플리케이션 앞에서 분리할 수 있다.
- 공개 DNS와 인터넷 인바운드 포트를 추가하지 않는다.
- 새 태블릿과 TV에는 로컬 CA 설치가 필요하다.
- NAS LAN 주소가 바뀌면 인증서를 다시 발급하거나 `yong.local`을 사용해야
  한다.
- TV가 사설 CA 설치를 지원하지 않으면 E3에서 공인 인증서가 있는 로컬
  DNS 이름 또는 별도 출력 장치를 재평가한다.

## 검증

- 로컬 CA로 LAN HTTPS의 인증서 체인과 호스트 이름 검증
- LAN HTTPS 상태·런타임 API 응답
- 공용 태블릿 등록과 `local_only=1` 기기·독립 자격정보 생성
- 같은 유형의 자격정보가 외부 네트워크에서 거부되는 통합 테스트
- 실제 공용 태블릿과 대상 TV의 CA 설치·브라우저 호환성
