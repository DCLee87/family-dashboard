# ADR-031: 부모 브라우저 비밀번호 로그인

- 상태: 구현 및 로컬 검증 완료, 공개 HTTPS 검증 대기
- 결정일: 2026-08-11

## 배경

부모 모바일의 Tailscale VPN 연결이 Android 결제 기능과 충돌할 수 있고,
배우자는 별도 VPN 앱 설치를 원하지 않는다. Synology QuickConnect는 DSM과
Synology 앱을 위한 중계 서비스이므로 임의의 Docker 웹 앱을 그대로 공개하는
진입점으로 사용하지 않는다. 반면 인터넷에 단순 포트 포워딩하고 기존 4자리
관리자 PIN만 사용하는 것은 ADR-018의 보안 원칙을 만족하지 못한다.

## 결정

- 아빠와 엄마는 서로 독립된 12~128자 비밀번호 계정을 사용할 수 있다.
- 비밀번호 원문은 저장하지 않고 Argon2id 해시만 SQLite에 저장한다.
- 로그인 성공 시 해당 브라우저를 부모 모바일 기기로 등록하고 기존의
  30일 access/90일 refresh 자격정보와 Secure·HttpOnly·SameSite=Strict
  쿠키를 발급한다.
- 로그인은 보기 권한만 부여한다. 일정 수정, 기기 관리 등은 기존 4자리
  관리자 PIN으로 관리자 모드를 추가 해제해야 한다.
- 비밀번호가 5회 연속 실패하면 해당 부모 계정을 15분간 잠그고 로그인
  성공 시 실패 횟수를 초기화한다.
- 비밀번호 변경 또는 계정 비활성화 시 그 계정의 비밀번호 로그인으로
  발급된 기존 기기와 세션을 모두 폐기한다.
- 로그인·로그아웃·계정 변경 요청은 동일 출처 검사를 적용한다. 계정 변경은
  신뢰 PC 또는 아빠 부모 모바일의 활성 관리자 세션과 CSRF 토큰을 요구한다.
- 기존 LAN/Tailscale 일회용 등록 흐름은 공용 태블릿과 이전 기기 호환을 위해
  유지한다. 부모 외부 접속의 기본 경로는 비밀번호 로그인으로 전환한다.
- 앱 로그인 구현만으로 인터넷 공개를 승인하지 않는다. Synology Reverse
  Proxy, 유효한 공개 인증서, 443만의 최소 공개, 로그인 공격 관찰과 복구
  절차를 실제 기기에서 검증한 뒤 별도로 공개한다.

## 결과와 단점

- 배우자는 Tailscale 앱 없이 일반 브라우저로 접속할 수 있다.
- 공개 주소는 누구나 접근을 시도할 수 있으므로 비밀번호 추측, 취약점 탐색,
  서비스 거부 공격과 로그·업데이트 관리 부담이 새로 생긴다.
- 계정 잠금은 무차별 대입을 줄이지만 공격자가 특정 부모 계정을 일시적으로
  잠그는 방해를 할 수 있다.
- 비밀번호 분실·유출 대응, 인증서 갱신, NAS 또는 인터넷 장애 시 가족 지원이
  운영 책임이 된다.
- 현재 비밀번호와 관리자 PIN의 2단계 분리는 적용하지만 별도 TOTP·패스키는
  포함하지 않는다. 공개 운영 관찰 결과에 따라 추가 인증을 검토한다.
