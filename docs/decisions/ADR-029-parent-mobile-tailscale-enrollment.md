# ADR-029: 부모 모바일의 Tailscale 주소 등록

- 상태: 승인
- 결정일: 2026-08-06

## 배경

ADR-019는 부모 모바일의 최초 등록을 기본적으로 집 안 네트워크에서
수행하도록 정했다. 운영에서는 LAN 주소 `yong.local`과 Tailscale Serve
주소가 서로 다른 브라우저 출처이므로, LAN에서 발급된 기기 쿠키를
Tailscale 주소에서 사용할 수 없다. 그 결과 집에서 정상적으로 승인한
휴대폰도 외부 주소에서는 다시 미등록 기기로 보였다.

## 결정

- 부모 모바일은 집 안 네트워크뿐 아니라 Tailscale Serve가 확인한
  tailnet 요청에서도 등록 코드를 제출할 수 있다.
- Tailscale 등록도 관리자 모드에서 생성한 10분짜리 일회용 코드와 신뢰
  PC의 최종 승인을 모두 요구한다.
- Tailscale 신원 헤더만으로 앱 권한이나 기기 인증정보를 발급하지 않는다.
- Tailscale 경로에서 허용하는 등록 유형은 `parent_mobile`로 제한한다.
- 공용 태블릿, TV와 최초 신뢰 PC 설정은 계속 집 안 네트워크 전용이다.
- 서로 다른 출처의 쿠키는 공유하지 않는다. 한 휴대폰이 두 주소를 모두
  사용할 필요가 있으면 주소별 등록으로 별도 기기 인증정보를 발급한다.

## 결과

- 부모 휴대폰은 주 사용 주소인 Tailscale HTTPS 화면에서 직접 등록하고
  이후 같은 주소로 외부 접속할 수 있다.
- 탈취된 등록 코드만으로는 등록할 수 없으며 tailnet 접근과 신뢰 PC의
  승인이 추가로 필요하다.
- LAN과 Tailscale 주소에 각각 등록하면 관리 화면에 같은 물리 기기의
  레코드가 두 개 보일 수 있으므로, 사용하지 않는 주소의 레코드는
  관리자가 폐기한다.
