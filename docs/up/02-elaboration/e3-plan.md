# E3 모바일 PWA 검증 계획

- 상태: 진행 중
- 시작일: 2026-07-29
- 범위: 부모 모바일과 공용 Android 태블릿

## 배경

E2에서 신뢰 PC, 부모 모바일과 공용 Android 태블릿의 등록·인증·관리자
모드를 실제 NAS 환경에서 검증했다. 사용자가 TV 검증과 NAS 복구 시험을
후속으로 연기했으므로 E3에서는 먼저 모바일 PWA 설치성과 Web Push 위험을
검증한다. 연기한 항목은 완료로 간주하지 않는다.

## 목표

1. Android Chrome에서 설치 가능한 PWA 기준을 충족한다.
2. 설치 후 독립 실행 화면과 기본 오프라인 셸을 확인한다.
3. 부모 모바일 Web Push 구독·저장·폐기 경계를 설계한다.
4. 실제 부모 모바일에서 권한 허용, 수신과 기기 폐기 연동을 검증한다.

- [x] manifest, Service Worker와 설치 아이콘 기준선 보완
- [x] 로컬 프로덕션 빌드와 정적 산출물 검증
- [x] 서버 중단 후 오프라인 앱 셸 렌더링 검증
- [x] Android Chrome 설치 및 독립 실행 검증
- [x] Push 구독 데이터 모델과 API 경계 결정
- [x] VAPID 키 운영·백업 정책 결정
- [x] Push 구독·해지와 기기 폐기 연동 구현
- [x] 테스트 알림 발송과 부모 모바일 실수신 검증
- [ ] 장시간 사용 중 Service Worker 갱신 동작 확인

## 실기기 인수 기준

- 홈 화면 아이콘에서 실행하면 브라우저 주소창 없는 독립 화면이 열린다.
- 새로고침 후 기기 인증과 보기 모드가 유지된다.
- 네트워크 단절 시 가족 데이터를 캐시해 노출하지 않고 앱 셸 또는 명확한
  연결 실패 상태를 표시한다.
- 알림 권한은 사용자 동작으로만 요청하고 거절 후 반복해서 방해하지 않는다.
- 폐기된 기기의 Push 구독으로 알림을 보내지 않는다.
- 알림 본문은 일정 공개 범위 정책을 적용한다.

### 2026-07-29 부모 Android 모바일

- NAS 배포 버전: `e3-mobile-pwa-20260729`
- Tailscale HTTPS 주소에서 manifest와 설치 아이콘 응답 확인

- 설치 아이콘으로 실행했을 때 독립 PWA 화면 표시 확인

- 알림을 눌렀을 때 등록된 PWA 화면으로 진입 확인
