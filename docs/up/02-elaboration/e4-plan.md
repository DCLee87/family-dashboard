# E4 도메인·아키텍처 기준선 계획

- 상태: 진행 중
- 시작일: 2026-07-29
- 범위: 일정 우선, 할 일과 알림 데이터 흐름 후속

## 목표

1. 일정의 시간, 반복, 예외와 겹침 규칙을 구현 가능한 수준으로 확정한다.
2. 가족 구성원, 일정과 최종 회차의 데이터 모델을 정의한다.
3. 기기 권한별 API 경계에서 공개 범위가 누출되지 않게 한다.
4. Construction 진입 전에 자동화할 인수 시험을 확정한다.
5. 같은 패턴을 할 일 반복·회차·알림 모델에 적용한다.

## 일정 인수 시험 기준선

### 시간과 날짜

- `09:00~10:00`과 `10:00~11:00`은 겹치지 않는다.
- 종료가 시작과 같거나 빠른 시간 일정은 저장되지 않는다.
- `2026-07-20~2026-07-22` 종일 일정은 20, 21, 22일에 표시된다.
- 종일 일정은 명시적 상태 반영 구간 없이는 예상 상태가 되지 않는다.
- 자정을 넘는 시간 일정은 두 날짜의 일정 화면에 일관되게 나타난다.

### 반복과 예외

- 화·목 반복은 기간 안의 화요일과 목요일에만 생성된다.
- 포함 종료일이 선택 요일이면 마지막 회차가 생성된다.
- 취소한 회차만 사라지고 다른 회차는 유지된다.
- 시간을 옮긴 회차도 원래 회차 키로 다시 수정·취소할 수 있다.
- 원본과 같은 회차 키에는 예외가 두 개 저장되지 않는다.
- 62일을 넘는 무제한 목록 조회는 명확한 검증 오류를 반환한다.

### 겹침과 상태

- 대상 가족이 한 명이라도 같고 시간 구간이 교차하면 경고한다.
- 겹침 경고 후 명시적 확인을 하면 저장할 수 있다.
- 활성 장소 일정 중 시작 시각이 가장 늦은 일정이 상태가 된다.
- 시작 시각이 같은 경우 ADR-027 순서로 항상 같은 결과를 선택한다.
- 모든 겹친 일정은 상세에서 조회되고 상태에는 겹침 표시가 붙는다.

### 권한과 공개 범위

- 권한 없는 일정 목록에 부모 전용 상세 객체가 포함되지 않는다.
- TV 요약 응답에는 실제 제목, 장소, 메모와 추론 가능한 내부 ID가 없다.
- 부모 전용 일정이 상태를 결정하면 권한 없는 화면에는
  `개인 일정`과 종료 시각만 표시된다.
- 클라이언트가 기기 프로필을 위조해도 서버 투영은 바뀌지 않는다.
- 모든 쓰기는 유효한 관리자 모드가 없으면 거부된다.

### 삭제와 동시성

- 전체 반복 삭제는 원본과 모든 회차를 일반 조회에서 제외한다.
- 한 회차 삭제는 취소 예외만 만들고 원본은 유지한다.
- 휴지통 복원은 30일 안에 가능하다.
- 오래된 버전으로 수정하면 `409 Conflict`가 발생하고 새 값을 덮지 않는다.
- 저장 실패 시 일정, 참여자와 요일 일부만 남지 않는다.

## 검증 층

| 층 | 대상 | 필수 검증 |
|---|---|---|
| 단위 | 회차 생성, 겹침, 상태 선택, 공개 투영 | 경계값·동률·권한별 테이블 시험 |
| 저장소 | SQLite 제약과 트랜잭션 | 외래 키, 고유 키, 롤백, 마이그레이션 |
| HTTP | 관리자/보기 API | 인증, 검증 오류, 409, DTO 누출 검사 |
| UI | PC 입력과 모바일·태블릿 보기 | 겹침 확인, 공개 범위 표시, 시간대 표시 |
| NAS | 실제 이미지와 기존 DB 업그레이드 | 백업, 마이그레이션, 재시작, 무결성 |
