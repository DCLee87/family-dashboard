# E2 보안·외부 접속 기준선 계획

- 상태: 진행 중
- 시작일: 2026-07-26
- 선행 조건: E1 NAS 경량 실행 기준선 완료

## 목표

가족 데이터를 인터넷에 공개하지 않은 상태에서 신뢰 경계와 공격 경로를
정의하고, HTTPS 외부 접속과 등록 기기 인증의 구현 기준선을 검증한다.
관리자 PIN은 기기 인증을 대체하지 않고 인증된 기기 안에서만 추가 권한을
잠금 해제한다.

## 범위

### 포함

- 초기 신뢰 PC 설정
- 부모 모바일, TV와 공용 태블릿 등록·승인·폐기
- 기기별 독립 자격정보와 권한
- 로컬 전용 기기의 외부 사용 차단
- 관리자 PIN 해시, 실패 제한과 10분 자동 잠금
- HTTPS와 VPN·Reverse Proxy 비교
- 인증정보 갱신, 폐기와 감사 이벤트
- 등록·복구 코드의 난수, 만료와 일회 사용
- 보안 관련 SQLite 스키마와 최소 API 프로토타입

### 제외

- 실제 일정·할 일·공지 데이터
- Web Push 전송
- 가족별 상세 공개 범위 필터링
- 인터넷 포트 공개
- 실제 가족 데이터 입력
- 백업·복구 구현

제외 항목 중 외부 백업과 복구 절차는 실제 가족 데이터 운영 전에 별도로
해결해야 한다.

- [x] 보호 자산, 신뢰 경계와 공격자 정의
- [x] 초기 설정, 등록, 일반 보기, 관리자 잠금 해제와 폐기 흐름 분석
- [x] 위협별 예방·탐지·복구 통제 연결
- [x] 보안 요구사항 추적표 작성

### E2.2 외부 접속 결정

- [x] VPN과 HTTPS Reverse Proxy 비교
- [x] 인증서, 도메인, 모바일 사용성과 운영 부담 검토
- [x] DSM·Container Manager 비공개 원칙 확인
- [x] 선택 결과를 새 ADR로 승인

### E2.3 인증 설계

- [x] 기기·등록 요청·세션·PIN·복구 코드 데이터 모델

- [x] 로컬 네트워크 판정 및 신뢰 프록시 규칙
- [x] CSRF, XSS, 쿠키와 브라우저 저장소 정책

- [x] 보기 권한과 관리자 권한 분리
- [ ] PIN 잠금 해제·자동 잠금·실패 제한

## 인수 기준

- [ ] 인증되지 않은 외부 요청은 가족 보기 데이터를 받지 못한다.
- [ ] 기기별 자격정보는 서로 독립적이며 원문으로 저장되지 않는다.
- [ ] 폐기된 자격정보는 즉시 거부된다.
- [ ] 등록·초기 설정·복구 코드는 만료되고 한 번만 사용할 수 있다.
- [ ] TV 자격정보로 편집·관리·복구 API를 사용할 수 없다.
- [ ] 로컬 전용 기기 자격정보는 외부 네트워크에서 거부된다.
- [ ] PIN 원문을 저장하지 않고 실패 제한과 자동 잠금을 서버에서 적용한다.
- [x] 외부 접속은 HTTPS 또는 승인된 사설 네트워크를 사용한다.
- [x] DSM 관리 화면과 Container Manager를 인터넷에 공개하지 않는다.
- [ ] 민감정보가 Git, API 오류 또는 운영 로그에 노출되지 않는다.

## 안전 게이트

- 외부 접속 방식 ADR 승인 전에는 라우터 포트 포워딩을 설정하지 않는다.
- 인증 프로토타입의 거부 테스트가 통과하기 전에는 외부 접속을 활성화하지
  않는다.
- 백업·복구 절차가 마련되기 전에는 실제 가족 데이터를 입력하지 않는다.
- PIN, 토큰, 등록 코드, 복구 코드와 개인키는 Git 또는 문서에 기록하지
  않는다.
