# Construction 진입 검토

- 상태: 조건부 준비
- 작성일: 2026-07-29

## 준비된 기준선

- E1: DS216+II 단일 컨테이너·SQLite·자원·재시작 기준선
- E2: 기기 등록, 관리자 PIN, HTTPS와 Tailscale 외부 접속 기준선
- E3 모바일: Android PWA 설치와 실제 Web Push 수신 기준선
- E4 일정: 시간·반복·예외 의미론, 데이터 모델, API, 유스케이스와 추적표
- E4 할 일·알림: 회차·알림 의미론, 데이터 모델과 요구사항 추적표

## Construction을 시작해도 되는 이유

- C1은 이미 실기기 검증된 E2/E3 인증·배포 기반을 재사용한다.
- 일정의 미결정 시간·회차·공개 범위 규칙은 ADR-027로 승인됐다.
- DB, 도메인, API와 UI를 잇는 작은 범위와 자동화 완료 조건이 있다.
- 운영 NAS 적용은 구현 완료와 별개 게이트로 분리되어 데이터 위험을
  통제한다.

## 남아 있지만 C1 로컬 구현을 막지 않는 항목

- 삼성 TV 브라우저·3 m 가독성·장시간 실행
- Service Worker 장시간 갱신 관찰
- NAS 외부 백업 대상과 전체 복원 실기기 시험
- TV 첫 화면 목표 시간 수치 확정
- iOS PWA·Web Push 실기기 확인

이 항목들은 Elaboration 전체 완료로 표시하지 않으며 Transition이나
관련 Construction 반복의 NAS 적용 전에 다시 게이트로 확인한다.

## 시작을 막는 조건

- 승인된 ADR과 충돌하는 DB 구조가 필요한 경우
- 기존 인증·기기 폐기·공개 범위 서버 필터를 우회해야 하는 경우
- 실제 가족 데이터를 개발·시험 데이터로 사용해야 하는 경우
- 운영 NAS에 백업 없이 migration을 적용해야 하는 경우
- C1 범위에 반복·알림·할 일·날씨를 동시에 포함하려는 경우

## 결정

Elaboration은 아직 진행 중으로 유지하되 C1의 로컬 구현과 CI 검증을
시작할 수 있다. C1의 운영 NAS 배포는 자동화 완료 후 사용자 승인과
백업 확인을 별도로 요구한다.
