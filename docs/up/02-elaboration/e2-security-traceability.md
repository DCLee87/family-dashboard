## 적용 순서

1. 토큰·코드·PIN 저장과 원자적 소비를 단위 테스트한다.
2. HTTP 통합 테스트에서 기본 거부와 기기별 권한 행렬을 고정한다.
3. 프록시·외부 주소 관련 통제는 신뢰 프록시 설계 후 통합 테스트한다.
4. NAS에서 HTTPS, 로컬 전용 제한, 폐기와 재부팅 복구를 실측한다.
5. 실제 가족 데이터 없이 로그와 SQLite에 비밀 원문이 없는지 검사한다.

## 추적 공백

- 일정·할 일·공지와 날씨 데이터가 E2에 없으므로 QR-SE-004, 011, 012의
  실제 필드 필터링은 도메인 API 반복에서 다시 검증한다.
- Push가 E2 범위 밖이므로 QR-SE-010은 저장·로그 설계까지만 검토하고 전송
  시험은 후속 반복에서 수행한다.
