# E2 NAS 보안·외부 접속 검증 기록

- 검증일: 2026-07-26~2026-07-27
- 대상: Synology DS216+II, DSM 7, linux/amd64
- 애플리케이션: `e2-20260726`
- 데이터: E1 런타임 시험 데이터만 사용

실제 주소, Tailnet 이름, 사용자 계정, 초기 설정 코드, 관리자 PIN, 복구
코드와 인증 토큰은 이 문서에 기록하지 않는다.

## 배포와 데이터 보존

- [x] E1 컨테이너를 정지한 상태에서 SQLite DB/WAL/SHM을 함께 백업
- [x] 기존 Compose 파일을 같은 시점의 백업 디렉터리에 보관
- [x] E2 linux/amd64 이미지의 전송 전후 SHA-256 일치 확인
- [x] E1 데이터 볼륨을 그대로 마운트해 E2 SQLite 스키마로 마이그레이션
- [x] 배포 후 SQLite 상태 API 정상
- [x] E2 버전과 컨테이너 재기동 확인

백업은 NAS 배포 디렉터리 아래의 시각별 `backups/pre-e2-*` 디렉터리에
보관한다. 외부 백업과 실제 복구 시험은 아직 완료되지 않았으므로 실제 가족
데이터를 유일본으로 입력하지 않는다.

## 사설 HTTPS

- [x] NAS Tailscale을 공식 DSM 7 x86_64 패키지 `1.98.9`로 갱신
- [x] Mac과 NAS가 같은 Tailnet에서 직접 통신
- [x] Tailscale Serve가 HTTPS 443을 컨테이너의 loopback 8080으로 프록시
- [x] Serve 상태가 `tailnet only`임을 확인
- [x] Funnel 미사용
- [x] TLS 1.3 연결과 공개 신뢰 인증서 검증 성공
- [x] HTTPS 상태 API가 HTTP 200과 정상 DB 상태 반환
- [x] NAS LAN 주소의 8080 직접 연결 거부 확인
- [x] Wi-Fi를 끈 부모 모바일의 이동통신망에서 HTTPS 접속·새로고침 확인

공유기 포트 포워딩을 만들지 않았으며 DSM과 Container Manager를 인터넷에
공개하지 않았다.

## 최초 신뢰 기기

- [x] 초기 설정 필요 상태가 HTTPS UI에 표시됨
- [x] NAS 로그에만 표시되는 10분 일회용 초기 설정 코드 사용
- [x] Mac을 최초 신뢰 PC로 등록
- [x] 숫자 4자리 관리자 PIN 설정
- [x] 일회용 복구 코드를 사용자에게 한 번 표시
- [x] 초기 설정 완료 후 서버 상태가 `setupRequired: false`로 전환
- [x] 인증 쿠키가 없는 기기 조회 요청이 HTTP 401로 거부
- [x] E2 재배포 후 최초 신뢰 PC의 기기 인증 유지
- [x] 등록된 Mac에서 올바른 PIN으로 관리자 모드 잠금 해제
- [x] 관리자 모드에서 즉시 잠금 후 보기 모드 복귀
- [x] 부모 모바일 등록 코드 생성과 모바일 제출
- [x] 신뢰 PC에서 부모 모바일 요청 최종 승인
- [x] 승인된 모바일에 독립 기기 인증정보 발급
- [x] 이동통신망에서 승인된 모바일의 기기 인증 유지
- [ ] 동일 초기 설정 코드 재사용 거부 실측
- [ ] 관리자 PIN 5회 실패 제한·5분 차단 실측
- [x] 부모 모바일 관리자 모드 10분 유휴 후 보기 모드 자동 복귀
- [ ] 신뢰 PC 관리자 모드 10분 유휴 자동 잠금 실측
- [ ] 부모 모바일의 관리자 PIN 잠금 해제·즉시 잠금
- [ ] 부모 모바일 폐기 후 즉시 접근 거부와 신뢰 PC 인증 유지
- [ ] 컨테이너와 NAS 재부팅 후 기기 인증 유지

복구 코드의 실제 값과 보관 위치는 기록하지 않는다. 사용자는 종이 또는
신뢰할 수 있는 비밀번호 관리자에 별도 보관한다.

## 남은 E2 실기기 시험

1. 로컬 전용 공용 기기를 등록하고 Tailnet 경로에서 거부되는지 확인한다.
2. 관리자 PIN 실패 제한과 자동 잠금을 검증한다.
3. 부모 모바일의 관리자 모드와 기기 폐기 후 즉시 거부를 검증한다.
4. 등록·복구 코드 재사용 거부를 추가 실측한다.
5. NAS 재부팅 후 인증 쿠키, SQLite 무결성과 Serve 자동 복구를 확인한다.
6. 외부 백업 매체와 복구 절차를 구현하고 실제 복구 시험을 수행한다.
