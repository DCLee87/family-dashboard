# C6 사용성·알림 신뢰성 마감

- 상태: NAS 배포 완료, 실기기 검증 진행 중
- 작성일: 2026-08-08
- 기준: ADR-014, ADR-016, ADR-017, FR-SCH, FR-TODO, FR-NOTE, FR-WEA, FR-DSH

## 구현 범위

- 공지·메모의 인라인 수정, 보관함 재게시, 휴지통 복원·영구 삭제
- 중요 공지의 아빠·엄마 모바일 Push 수신자 선택
- 장소 검색, 지도 위치 확인, 목록·수정·삭제와 일정의 등록 장소 연결
- 현재 날씨, 기기별 1~7일 예보와 0~48시간 시간별 예보 범위
- 날씨 요청 3회 제한 재시도와 마지막 성공 데이터 장애 격리
- PC에서 PC·모바일·태블릿·TV별 위젯과 날씨 표시 범위 설정
- 일정별 복수 알림 시각과 아빠·엄마 모바일 수신자 선택
- 최대 7일 알림 워커 중단 구간 재처리
- 중요한 기한 초과 할 일의 매일 오전 9시 회차별 재알림
- 일정·할 일·공지 1분 자동 갱신, 날씨 10분 자동 갱신과 TV 확대 배치
- 하단 `아빠·엄마·딸·가계부·재테크·설정` 탭과 가족별 일정·할 일 필터
- 월간 일정 캘린더와 월 이동, 날짜 선택, 선택 날짜 일정 등록·수정 흐름
- 딸 탭의 월~일 주간 학원 시간표, 주 이동과 빈 요일 표시
- 일정의 일반·학원·방과후 태그와 딸 시간표 태그 필터, 학원·방과후의 매주 반복 기본값
- 서비스 상태, 런타임, 관리자 모드, Push와 기기별 화면 설정의 설정 탭 통합
- 설정 탭의 VPN 앱 없는 배우자 초대와 부모별 브라우저 로그인 가이드
- 아빠·엄마별 Argon2id 비밀번호, 실패 잠금, 로그인 기기 발급·로그아웃과 비밀번호 변경 시 기존 세션 폐기
- 관리자 PIN을 연 아빠 부모 모바일의 등록 요청 확인·승인과 등록 기기 관리
- 매월 21일을 시작일로 하는 월급 예산과 지출 입력·수정·삭제·기간 합계
- 부모 기기에서만 조회하는 대출 원금·금리·월 상환액과 적금 납입액·만기 관리

## 데이터와 호환성

- SQLite schema 16을 사용한다.
- 기존 C5 데이터는 유지되며, 기존 일정 알림은 현재 단일 알림값과 부모 모바일
  전체 수신자를 복수 알림 테이블의 초기값으로 이전한다.
- 새 테이블은 `schedule_places`, `schedule_notification_times`,
  `schedule_notification_recipients`, `board_notification_recipients`,
  `device_weather_preferences`, `notification_worker_state`, `parent_accounts`,
  `parent_login_events`, `parent_login_devices`다.
- 알림 중단 구간은 최대 7일까지만 재처리하여 장기간 중단 후 과도한 Push를
  제한한다.
