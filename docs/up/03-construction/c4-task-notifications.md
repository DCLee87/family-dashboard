# C4 할 일과 알림 수직 조각

- 상태: 구현·로컬·패키지 검증 완료, NAS 배포 대기
- 작성일: 2026-08-07
- 기준: ADR-012~015, ADR-028, E4 할 일·알림 추적표

## 목표

관리자가 일회성·매일·매주 할 일을 등록하고 회차를 완료하거나 건너뛸 수
있게 한다. 마감 유형과 담당 가족에 따른 기본 부모 모바일 알림을 제공하고,
완료 기록과 건너뛴 회차를 관리자 화면에서 복원할 수 있게 한다.

## 포함 범위

- 제목·메모·우선순위·복수 담당자와 선택적 마감
- 일회성·매일·매주 회차와 회차별 완료·완료 취소
- 반복 회차 건너뛰기와 관리자 복원
- 완료 기록 조회와 미완료 복원
- 직접 삭제, 30일 휴지통, 복원과 영구 삭제
- 마감 시각 1시간 전, 날짜 마감 오전 9시 기본 알림
- 아빠·엄마 담당 조합 기반 기본 부모 모바일 수신자
- 할 일별 알림 끄기, 시점과 부모 수신자 변경
- 회차·기기·알림 시점 기반 중복 Push 방지

## 이번 조각의 제한

- 장기 중단 중 모든 과거 미완료 회차를 물리 행으로 선행 생성하는
  watermark 복구는 후속 성능 반복에서 구현한다.
- 중요 기한 지난 회차의 매일 오전 9시 재알림은 과도한 알림 방지 정책과
  장기 회차 생성 범위를 함께 확정한 뒤 추가한다.
- Android 실제 Push, 태블릿 표시와 NAS 자원 사용은 배포 후 실기기에서
  확인한다.

## 자동 검증

- SQLite schema 11 마이그레이션과 알림 테이블 제약
- 아빠 단독·엄마 단독·복수 담당자의 기본 수신자 계산
- 시간 마감 1시간 전과 날짜 마감 오전 9시 계산
- 반복 회차별 알림 시각과 중복 발송 방지 키
- 완료·완료 취소, 건너뛰기·복원과 완료 기록 조회
- 단일 SQLite 연결에서 할 일·관계 조회 교착 방지
- React 빌드와 전체 Go 테스트
