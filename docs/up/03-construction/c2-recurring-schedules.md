# C2 반복 일정과 회차 예외 계획

- 상태: 준비 중
- 작성일: 2026-08-07
- 기준: ADR-004, ADR-009, ADR-027, E4 일정 유스케이스·추적표

## 반복 목표

관리자가 매주 반복하는 시간 일정과 종일 일정을 등록하고, 특정 회차만
수정하거나 취소할 수 있게 한다. 목록·가족 상태·겹침·공개 범위는
반복 원본이 아닌 최종 회차 기준으로 C1과 같은 방식으로 동작해야 한다.

## 포함 범위

- `weekly` 반복 원본: 현지 시작일, 종료일, 선택 요일, 현지 시작·종료 시각
- 포함 종료일과 명시적 무기한 반복 규칙
- 반복 회차의 안정적인 `occurrence_key`
- 한 회차의 시간·제목·장소·공개 범위 변경과 취소 예외
- 종일·여러 날 일정의 포함 날짜 표시
- 62일 조회 제한과 반복 회차 생성·겹침·상태 계산
- 관리자 UI의 반복 입력, 회차 수정·취소 최소 흐름

## 제외 범위

- 전체 반복 삭제와 휴지통·복원
- 일정 알림과 예약 작업
- 반복 규칙의 복잡한 월간·음력·사용자 정의 패턴
- 종일 일정의 별도 상태 반영 시간 구간 편집 UI
- TV 전용 레이아웃 마감

## 안전 규칙

- 반복 규칙은 `Asia/Seoul`의 현지 날짜·시각으로 저장하고 실제 회차는 UTC로
  계산한다.
- 종료일은 포함하며, 회차 키는 원래 현지 시작 날짜·시각을 유지한다.
- 이동한 회차도 원래 회차 키로 다시 수정·취소한다.
- 원본 하나와 회차 키 하나에는 예외를 하나만 저장한다.
- 반복 원본 수정으로 유효하지 않아진 기존 예외는 묵시적으로 삭제하지
  않고 충돌로 돌려준다.
- 겹침 경고와 공개 범위 투영은 최종 회차에 적용한다.

## 작업 순서

1. C1 스키마를 확장하는 migration과 반복·예외 저장소 시험을 작성한다.
2. 회차 생성, 예외 적용, 종일 날짜 포함과 62일 범위 검증 순수 함수를 만든다.
3. 읽기 API가 일회성·반복·예외의 최종 회차를 함께 반환하도록 확장한다.
4. 반복 원본·회차 예외 쓰기 API와 겹침 경고를 연결한다.
5. 관리자 UI에 반복 입력과 이번 회차 수정·취소를 추가한다.
6. 권한별 공개 범위, 모바일·태블릿 새로고침과 NAS 배포를 검증한다.

## 완료 조건

- [ ] 화·목 반복이 요청 범위에서만 생성된다.
- [ ] 종료일이 선택 요일이면 마지막 회차가 포함된다.
- [ ] 취소·변경 회차가 재시작 뒤에도 유지된다.
- [ ] 이동한 회차를 원래 회차 키로 다시 찾을 수 있다.
- [ ] 종일·여러 날 일정이 양끝 날짜를 포함해 표시된다.
- [ ] 반복 회차가 C1 일정과 겹칠 때 같은 경고·상태·공개 규칙을 따른다.
- [ ] Go·웹·Docker·NAS 검증이 통과한다.
