# C7 가계부·대출·적금 사용성 고도화

- 상태: NAS 배포 및 운영 HTTPS 기본 검증 완료
- 작성일: 2026-08-15
- 기준: C6, schema 16

## 목표

매월 21일 월급을 기준으로 실제 생활비 흐름을 빠르게 파악하고, 대출 상환과
적금 납입 일정을 놓치지 않도록 기존 금융 화면을 고도화한다.

## 구현 범위

- 월급 기간 이전·현재·다음 이동과 최대 과거 10년, 미래 12개월 조회
- 선택 기간의 예산 사용률과 초과 상태 표시
- 카테고리별 지출 금액·비율 요약
- 지출 메모·분류 검색, 카테고리·결제자 필터
- 과거 기간에서 새 지출을 열 때 선택 기간 시작일을 기본 날짜로 적용
- 대출 상환액과 적금 납입액을 합친 월 고정 금융부담 표시
- 납부일이 29~31일인 경우 해당 월 말일로 보정한 다음 납부 일정
- 현재 원금과 금리에 따른 단순 연·월 예상 이자 참고값

## 데이터와 호환성

- SQLite schema 16을 그대로 사용하며 새 migration은 없다.
- 기존 월급 예산, 지출, 대출·적금 데이터와 API 기본 호출은 유지한다.
- `GET /api/v1/finance`에 선택형 `offset` query만 추가한다. 생략하면 기존처럼
  현재 월급 기간을 반환한다.
- 금융기관 비밀번호, 문자, 카카오톡을 수집하거나 크롤링하지 않는다.

- 배포 전 백업: `pre-c7-20260815T124907Z`
- 운영 런타임: `version=c7`, `database=ok`, `status=ok`
- 운영 화면: 가계부 이전·현재 기간 이동과 재테크 월 고정 금융부담 표시 확인

schema를 변경하지 않지만, 운영 NAS의 컨테이너 교체는 별도 사용자 승인을 받는다.
