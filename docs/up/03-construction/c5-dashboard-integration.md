# C5 공지·날씨·기기별 대시보드 통합

- 상태: 구현·로컬·패키지·NAS 배포 및 관리자 PC 검증 완료
- 작성일: 2026-08-08
- 기준: ADR-016, ADR-017, FR-NOTE, FR-WEA, FR-DSH

## 목표

일정과 할 일에 가족 공지·메모 및 기본 집 날씨를 더하고, 등록 기기별로
위젯 표시 순서를 저장할 수 있는 초기 통합 대시보드를 만든다.

## 포함 범위

- 공지·메모의 게시 기간, 중요도와 가족·TV 요약·부모 전용 공개 범위
- 종료된 게시 항목 자동 보관, 보관·재게시, 30일 휴지통과 영구 삭제 API
- 중요 공지의 부모 모바일 Push와 부모 전용 잠금 화면 비식별 문구
- 상세 주소 없이 장소명·시군구 표시명·WGS84 좌표를 저장하는 장소 관리
- Open-Meteo 현재 기온과 7일 예보, 30분 캐시와 실패 시 마지막 성공 데이터
- 24시간 이상 갱신하지 못한 예보 숨김 및 핵심 기능과 날씨 장애 격리
- PC·부모 모바일·공용 태블릿·TV의 기본 위젯 순서와 관리자 설정
- 모바일 2일, 태블릿 3일, PC·TV 5일 날씨 표시

## 데이터와 운영

- SQLite schema 12: `board_items`, `board_push_deliveries`, `places`,
  `weather_cache`, `dashboard_preferences`
- 날씨 공급자는 API 키가 필요 없는 Open-Meteo Forecast API를 사용한다.
- 좌표 입력 전에는 날씨 영역에 설정 필요 상태만 표시한다.
- 날씨 외부 요청은 5초 타임아웃이며 실패가 일정·할 일·공지 API를 막지 않는다.
