# E2 위협 모델

- 상태: 초안
- 작성일: 2026-07-26

## 보호 자산

- 가족 일정·할 일·공지와 예상 상태
- 기기 자격정보와 인증 세션
- 관리자 PIN 검증 정보와 복구 코드 검증 정보
- 등록 코드와 초기 설정 코드
- SQLite 데이터와 암호화·서명 키
- Push 구독 정보
- 보안 감사 기록

## 행위자

| 행위자 | 신뢰 수준 | 허용 범위 |
|---|---|---|
| NAS 운영자 | 최고 | 배포, 초기 설정 코드 확인, 백업·복구 |
| 등록된 부모 PC | 높음 | 보기, 기기 승인, PIN 복구, 관리자 잠금 해제 |
| 등록된 부모 모바일 | 높음 | 보기, PIN 입력 후 관리자 기능 |
| 등록된 공용 태블릿 | 제한 | 로컬 보기, PIN 입력 후 제한된 관리자 기능 |
| 등록된 TV | 최소 | 로컬 보기 전용 |
| 미등록 로컬 기기 | 없음 | 초기 등록 흐름 외 가족 데이터 접근 금지 |
| 외부 미등록 사용자 | 없음 | 모든 가족 데이터와 등록 기능 접근 금지 |

## 신뢰 경계

1. 인터넷과 외부 접속 계층
2. 외부 접속 계층과 애플리케이션
3. 가정 내 네트워크와 애플리케이션
4. 브라우저 저장소와 서버 측 자격정보
5. 애플리케이션과 SQLite·키 저장소
6. 일반 보기 세션과 관리자 모드
7. 애플리케이션 운영 로그와 운영자

## 초기 위협 목록

| ID | 위협 | 초기 통제 | 검증 |
|---|---|---|---|
| E2-T01 | 인터넷에서 인증 없이 가족 데이터 조회 | 기본 거부, 등록 기기 인증, HTTPS | 미인증 외부 요청 거부 테스트 |
| E2-T02 | 4자리 PIN 추측으로 관리자 권한 획득 | 기기 인증 선행, 5회 실패 후 5분 차단 | 기기별 실패 제한 테스트 |
| E2-T03 | DB 유출로 PIN·토큰 원문 노출 | 메모리 경도 비밀번호 해시, 토큰 해시 저장 | DB에 원문이 없는지 검사 |
| E2-T04 | 등록·복구 코드 재사용 | 10분 만료, 일회 사용, 원자적 소비 | 성공 후 재사용·동시 사용 거부 |
| E2-T05 | TV 토큰으로 편집 API 호출 | 서버 측 기기 유형·권한 검사 | TV 토큰 권한 매트릭스 테스트 |
| E2-T06 | 로컬 전용 토큰을 외부에서 사용 | 신뢰 프록시를 고려한 서버 측 네트워크 판정 | 외부 주소 모사 거부 테스트 |
| E2-T07 | 분실 기기의 장기 접근 | 개별 폐기, 마지막 사용 시각, 갱신 토큰 회전 | 폐기 즉시 기존 토큰 거부 |
| E2-T08 | 토큰 탈취 후 재사용 | Secure·HttpOnly 쿠키 우선, 짧은 세션, 갱신 회전 | 이전 토큰 재사용 거부 |
| E2-T09 | CSRF로 관리자 작업 실행 | SameSite 쿠키, Origin 검증, CSRF 통제 | 교차 출처 변경 요청 거부 |
| E2-T10 | XSS로 가족 데이터·세션 탈취 | 출력 인코딩, CSP, 토큰의 JS 비노출 | CSP와 위험 HTML 회귀 테스트 |
| E2-T11 | 프록시 헤더 위조로 로컬 기기 가장 | 신뢰 프록시 allowlist 밖의 전달 헤더 무시 | 위조 헤더 거부 테스트 |
| E2-T12 | 코드·토큰·PIN이 로그에 남음 | 구조화 로그 필드 제한과 비밀값 마스킹 | 로그 캡처 검사 |
| E2-T13 | 초기 설정 경합으로 공격자가 최초 PC 선점 | 로컬 제한, 고엔트로피 코드, 시도 제한, 원자적 완료 | 동시 초기 설정 시험 |
| E2-T14 | NAS·백업 유출로 키와 데이터 노출 | 최소 파일 권한, 비밀 분리, 외부 백업 보호 | 권한·복구 설계 검토 |

## 미결정 사항

- VPN과 HTTPS Reverse Proxy 중 기본 외부 접속 방식
- 브라우저 기기 자격정보의 쿠키·플랫폼 저장 방식
- 액세스·갱신 자격정보 수명
- PIN과 복구 코드의 구체적인 해시 알고리즘·파라미터
- 신뢰할 Reverse Proxy 주소와 실제 클라이언트 IP 판정
- 서버 서명·암호화 키의 생성, 권한, 교체와 백업 방식
- 최초 PC와 복구 코드를 모두 잃은 경우 운영자 복구 절차
